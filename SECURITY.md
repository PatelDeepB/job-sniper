# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and privacy of our users very seriously, especially because JobSniper handles resumes and career information.

If you discover a security vulnerability in JobSniper, please do NOT create a public GitHub issue. Instead, report it privately:

* **Email:** pateldeep9737@gmail.com
* **Subject:** `[SECURITY] JobSniper Vulnerability Report`

Please include:
1. Description of the vulnerability and its potential impact.
2. Step-by-step instructions or proof-of-concept to reproduce the issue.
3. Suggested remediations, if known.

We will acknowledge receipt within 48 hours and work with you to publish a coordinated advisory and patch.
